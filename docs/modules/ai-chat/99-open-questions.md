# ai-chat / 99 — Open Questions

Открытые вопросы модуля. Каждый имеет ID `Q-AICHAT-N`. Закрытые помечаются решением или ADR.

| ID | Вопрос | Статус | Решение/направление |
|---|---|---|---|
| Q-AICHAT-1 | Поддерживать ли несколько тредов на одну транскрибацию? | Deferred (v1: нет) | v1 — один тред на транскрибацию ([ADR-005](../../adr/ADR-005-thread-and-summary-model.md)). Расширение: добавить `thread_id` в chat_messages при появлении требования. Не блокирует v1. |
| Q-AICHAT-2 | Формат машиночитаемых structured_blocks от модели: отдельный JSON-вызов (tool/function calling) или парсинг fenced JSON из ответа? | Open | Предлагается начать с инструктированного fenced JSON + Pydantic-валидация на выходе, fallback `[]` (TD-006). При нестабильности — перейти на function calling (потребует уточнения, не блокирует v1, есть рабочий путь). |
| Q-AICHAT-3 | Должен ли `translate_or_adapt` брать целевой язык из `message`, поля `language` транскрибации или отдельного параметра? | Open | v1: целевой язык извлекается из пользовательского `message`; если не указан — модель просит уточнить (поведение системного prompt). Достаточно для v1. |

Примечание: ни один из вопросов не блокирует начало реализации v1 — для каждого зафиксировано рабочее решение по умолчанию.
