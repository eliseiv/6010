# ai-chat / 06 — RBAC

## Модель доступа (v1)

Сервис автономный, single-tenant. RBAC между конечными пользователями отсутствует.

| Принцип | Доступ |
|---|---|
| Носитель `X-API-Key` (валидный) | Полный доступ ко всем `/api/*` endpoints |
| Без ключа / неверный ключ | Только `GET /health`; остальное → 401 `unauthorized` |

- Нет ролей, нет разграничения данных между «пользователями»: любой держатель ключа видит и пишет в любые транскрибации и треды.
- «Пользователь» в ТЗ — логический владелец треда (один тред на транскрибацию), не субъект авторизации.

Обоснование — [ADR-003](../../adr/ADR-003-auth-api-key.md). Per-user RBAC и rate limiting — вне scope (TD-002).

## Реализация

- FastAPI dependency проверяет `X-API-Key` через `secrets.compare_digest` на всех роутерах `/api/*`.
- `/health` исключён из проверки.
