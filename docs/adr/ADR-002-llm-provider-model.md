# ADR-002 — LLM-провайдер OpenAI, модель и бюджет токенов

- Статус: Accepted
- Дата: 2026-06-09

## Context

Сервис генерирует ответы через LLM по контексту транскрибации. Пользователь зафиксировал провайдера **OpenAI** (`OPENAI_API_KEY`); Anthropic/Claude использовать запрещено. Нужно выбрать конкретную модель по умолчанию и бюджеты токенов с учётом NFR стоимости и простоты.

## Decision

- Провайдер: **OpenAI**, официальный клиент `openai>=1.54`.
- Модель по умолчанию: **`gpt-4o-mini`** (через env `OPENAI_MODEL`, переопределяемо).
  - Обоснование: дешёвая, быстрая, большой контекст (≈128k токенов), достаточного качества для summarization/extraction задач сервиса. Дорогие модели — опционально через env без изменения кода.
- Бюджет контекста по умолчанию: **`CONTEXT_TOKEN_BUDGET = 100000`** токенов (запас под системный prompt и ответ в окне модели).
- Лимит ответа: **`MAX_OUTPUT_TOKENS = 2000`**.
- Таймаут запроса к OpenAI: **`OPENAI_TIMEOUT_SECONDS = 60`**.
- Оценка токенов — через **tiktoken** (см. ADR-004).
- Запрет: никаких вызовов Anthropic/Claude. Зависимость `anthropic` в проект не добавляется.

## Consequences

- (+) Низкая стоимость и высокая скорость при достаточном качестве.
- (+) Модель и бюджеты конфигурируются через `.env` без правки кода.
- (−) `gpt-4o-mini` уступает флагманам в сложных рассуждениях; для типовых команд сервиса достаточно. При необходимости — смена `OPENAI_MODEL`.
- (−) Бюджет 100k — эвристика; реальное окно зависит от выбранной модели. При смене модели на меньшее окно нужно скорректировать `CONTEXT_TOKEN_BUDGET`.

## Alternatives

- **Anthropic/Claude** — запрещено пользователем.
- **gpt-4o / o-series** — отвергнуто как дефолт: дороже; доступно через `OPENAI_MODEL`.
- **Локальные модели** — отвергнуто: усложняют деплой на VPS, противоречат простоте.
