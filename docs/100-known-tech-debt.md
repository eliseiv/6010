# 100 — Known Tech Debt

Реестр известного технического долга. Каждый пункт имеет ID `TD-NNN`. Ссылки на него допустимы из `docs/` и кода вместо запрещённых `TODO/TBD`.

| ID | Описание | Severity | Статус |
|---|---|---|---|
| TD-001 | Не выбран инструмент lock-файла зависимостей (pip-tools / uv). Манифест — `pyproject.toml`. Выбор за devops при настройке CI. | low | open |
| TD-002 | Нет rate limiting на клиента/ключ. Возможен abuse и рост стоимости OpenAI. Митигируется бюджетом токенов и таймаутом. | medium | open |
| TD-003 | API без версионирования пути (нет `/v1`). Допустимо для v1; добавить при первом breaking change контракта. | low | open |

| TD-005 | Транскрибации хранятся в БД без шифрования колонок. Добавить при появлении PII-требований. | low | open |
| TD-006 | structured_blocks извлекаются из ответа LLM эвристически/через инструктированный JSON; нет строгой валидации схемы блоков на стороне модели. Валидируется Pydantic на выходе; при невалидном JSON — fallback на пустой список с пометкой. | medium | open |

## Severity

- **low** — не влияет на корректность v1, отложено осознанно.
- **medium** — стоит закрыть в ближайших итерациях.
- **high** — блокирует прод (на момент bootstrap отсутствуют).
